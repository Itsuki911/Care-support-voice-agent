# Voice Agent Lab

ダッシュボードと Agent 設定は実データに接続し、観測設定は Langfuse 接続状態を表示します。その他の画面は以下に記載する合成データによるモックです。

## ローカル起動

Node.js 22 以上と npm を使用します。`Test-LiveKit/.env` の Langfuse 認証情報をサーバー側で参照します。別の接続先を使う場合は `evaluation-web/.env.local` または起動時の環境変数に読み取り権限を持つ認証情報を設定します。環境変数側に接続設定が一つでもある場合は、その設定を優先し、両者を混ぜません。秘密鍵はサーバー側だけで使用し、ブラウザーへ渡しません。画面自体に認証機能はないため、信頼できる環境で利用してください。

```dotenv
LANGFUSE_BASE_URL=https://jp.cloud.langfuse.com
LANGFUSE_PUBLIC_KEY=
LANGFUSE_SECRET_KEY=
```

期間ボタンから開始日と終了日をカレンダーで選び、「適用」で表示を更新します。期間は日本時間の日付単位で両端を含み、最大366日です。初期値は今日を含む直近7日間です。選択期間は URL に保持されます。各リクエストで選択期間の Observations API v2 をページ取得します。セッション数は期間内に観測された sessionId の重複を除いた数、コストは GENERATION の取得できた totalCost の小計です。最近のセッションは期間内の観測開始日時で降順に最大10件表示します。評価は DeepEval 秘書評価が Langfuse に記録した `secretary.*`、`text.conv.*`、`voice.conv.*` の数値スコアを Scores API v3 から取得し、記録日時が期間内のスコアの算術平均と JST 日別平均を表示します。異なる指標・評価設定も含むため、厳密な同一条件比較ではありません。セッションのスコアは取得したトレースに紐づく同期間の評価の平均です。スコアを Langfuse に送信しなかった評価は対象外です。

認証情報不足・取得失敗時は未接続と表示します。安全性評価は未接続、未計測値は N/A です。セッション一覧・詳細画面は引き続きモックのため、実セッションへのリンクは表示しません。会話本文や入出力は取得しません。

```sh
cd evaluation-web
npm ci
npm run dev
```

ブラウザーで http://localhost:3000 を開きます。

```sh
npm run build
npm run typecheck
```

ダッシュボードの安全性テストは未接続です。サイドバーとクイックアクションは画面構成の確認用です。

## Agent 設定

`/config/agent` で OpenRouter の4モデルと temperature・reasoning_effort・max_tokens・prompt_caching の選択、通常セッションのシステムプロンプト編集、ツールの有効・無効、RAG パラメーター、メモリの件数と操作履歴・extraction_frequency、メモリ/RAG の利用設定を確認できます。保存内容は `Test-LiveKit/.agent-runtime-config.json` に保存され、次のセッションから読み込まれます。このファイルは Git 管理外です。既存のメール等の承認フローは変更しません。秘書モードは専用プロンプトを使用します。チャンクサイズと重なりは新規取り込みに適用され、既存文書には再取り込みが必要です。RAG の embedding_model は Ollama の 768 次元互換モデルを指定し、変更時には文書の再取り込みが必要です。metadata_filter、rerank_top_n、max_iterations、max_steps、max_execution_time、early_stopping_method は将来用として保存のみ行い、現在の RAG 動作には適用しません。画面に示す初期値は仮値です。通常の文書検索では、top_k はツールが明示指定しない場合の既定値、similarity_threshold は検索の下限値として使用します。

temperature と max_tokens の空欄、reasoning_effort の auto はプロバイダー既定値を使います。reasoning_effort と max_tokens は OpenRouter の追加リクエスト項目として指定し、モデルごとの対応に依存します。prompt_caching の無効化はアプリ側のキャッシュ指定を停止しますが、プロバイダーによる自動キャッシュを保証して停止するものではありません。

メモリの extraction_frequency は session_end（会話終了ボタン時、一括抽出）または every_response（各回答後、未処理分をバックグラウンド抽出）から選択できます。既定値は session_end です。変更は次のセッションから有効です。

LLM の比較は Langfuse の直近365日の `llm_request` と紐づく DeepEval スコアを集計します。条件や件数が異なるため厳密な比較実験ではありません。メモリ画面は PostgreSQL のテーブル件数と直近の操作種別・日時のみを読み取ります。DB に接続できない場合はその旨を表示します。音声モデルと音声の設定もハーネス画面で変更できます。認証情報は環境変数で管理します。Agent 設定の編集機能にはアプリ独自のユーザー認証がないため、ローカル環境で使用してください。起動コマンドは localhost に限定しています。

## セッション一覧

サイドバーの「セッション」またはダッシュボードの「すべて見る」から開きます（`/sessions`）。実装設計書 §4.3 をもとに、セッションIDの部分一致、モデル、評価状態、日時順、ページ切り替えを合成データで確認できます。条件は URL に保持します。詳細データがある `sess_8f3a2c9e` から詳細画面に移動できます。

## トレース一覧

サイドバーの「トレース」から開きます（`/traces`）。実装設計書 §4.4 をもとに、合成トレースを ID・スパン名・モデル・種別・状態・開始日で絞り込めます。検索条件は URL に保持します。詳細がある行からトレースとセッションの各詳細に移動できます。計測コスト小計は取得できた値を表示し、未計測件数を併記します。

## 評価結果一覧

サイドバーの「評価結果」から開きます（`/evaluations`）。実装設計書 §4.5 をもとに、通常評価の合成 Run を ID、状態、対象種別、評価設定で絞り込めます。検索条件は URL に保持します。サンプルの完了 Run からセッションの評価サマリーを開けます。

## 評価モニタリング

サイドバーの「評価モニタリング」から開きます（`/evaluators/monitoring`）。評価結果一覧と同じ合成 Run を Judge モデルで絞り込み、状態別件数、終了済み Run の実行成功率、計測済みの実行時間・トークン・USD コスト、構造化出力失敗率、指標欠損率を確認できます。計測がない項目は N/A と表示します。

## 安全性評価の概要

サイドバーの「Safety Evaluation」から開きます（`/safety`）。通常評価と独立した合成 Run をフレームワークで絞り込み、実行状態、判定済みケース数、不合格ケースの重大度を確認できます。実行失敗で未判定のケースは、合格・不合格ともに N/A と表示します。

## 安全性評価の新規 Run

安全性評価の概要にある「新規 Run の設定」から開きます（`/safety/new`）。合成データの対象・設定版・フレームワーク・データセット版・プロファイルを選び、「設定を確認」でプレビューを表示します。フレームワークは複数選択でき、未選択時は入力エラーを表示します。このモックの操作は設定の確認までです。

## 安全性評価の実行履歴

安全性評価の概要にある「実行履歴」から開きます（`/safety/history`）。合成 Run を ID、フレームワーク、データセット版、実行状態で絞り込めます。不合格件数を展開すると重大度の内訳を表示します。判定未取得や未計測は N/A と表示します。

## 安全性評価 Findings

安全性評価の概要にある「Findings を確認」から開きます（`/safety/findings`）。合成の指摘サンプルを ID・要約・重大度・カテゴリ・確認状態で絞り込めます。指摘を展開すると根拠、版情報、アノテーション、再検証の情報を確認できます。関連 Run から該当の実行履歴を開けます。

## 安全性評価のデータセット

安全性評価の概要にある「データセット」から開きます（`/safety/datasets`）。合成データセットを ID、カテゴリ、状態で絞り込み、版、ケース数、関連 Run の実行履歴を確認できます。

## 評価設定（DeepEval）

サイドバーの「評価設定（DeepEval）」から開きます（`/config/evaluator`）。設計書 §5.3 をもとに、Judge モデル、自動評価、指標の有効・無効、合格閾値の変更をプレビューできます。承認違反の必須チェックは固定です。設定の適用と評価エンジンは未接続です。

## 安全性設定

サイドバーの「安全性設定」から開きます（`/config/safety`）。固定ポリシーを表示し、既定のレビュー担当とマスキング済みレポートの保持期間の変更をプレビューできます。保存と適用は未接続です。

## 観測設定

サイドバーの「観測設定」から開きます（`/config/observability`）。通常トレースの取得率、ログレベル、マスキング済みログの保持期間の変更をプレビューできます。重大な安全性イベントの全件記録と秘密情報・個人情報の保護は固定表示です。Langfuse の Observations API をページ表示時に確認し、接続状況と確認日時を表示します。「接続を再確認」で再試行できます。設定の保存と適用は未接続です。

## 設定バージョン履歴

サイドバーの「設定バージョン履歴」から開きます（`/config/history`）。開発環境の合成履歴を設定種別・状態・キーワードで絞り込み、更新者・変更概要・現在の関連設定を確認できます。履歴からの適用とロールバックは未接続です。

## 通常評価データセット

サイドバーの「データセット」から開きます（`/datasets`）。合成データの版、ケース数、必要入力の充足率、作成元を確認できます。行を展開すると期待結果と失敗条件の例が表示され、関連する評価 Run や合成セッションへ移動できます。データの保存や編集は未接続です。

## アノテーション一覧

サイドバーの「アノテーション」から開きます（`/annotations`）。合成のレビューコメントを ID・コメント・ラベル・対象種別・レビュー状態から絞り込み、担当者や確認対象を参照できます。コメントの永続保存や一覧からの編集は未接続です。

## 実験（A/B テスト）

サイドバーの「実験（A/Bテスト）」または Agent 設定の実験タブから開きます（`/experiments`）。Agent 設定比較と固定出力の Judge 比較を切り替え、固定条件、ケース別スコア、欠損率を確認できます。平均と差分は両方の値があるケースで集計します。新規実験の実行と保存は未接続です。

## 実行履歴

サイドバーの「実行履歴」から開きます（`/runs`）。通常評価と安全性評価の合成 Run を日時順に表示し、種別・状態・ID で絞り込めます。各 Run のリンクは、該当 Run で絞り込んだ評価結果または安全性評価履歴を開きます。
